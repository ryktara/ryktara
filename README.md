## 🚀 BYBRetail ERP — Flagship Project

> **Enterprise Retail + Distribution ERP** — Built for scale, accuracy, and real operations.

📦 **Repository:** [github.com/ryktara/BYBRetail](https://github.com/ryktara/BYBRetail)

### What BYBRetail Covers

| Module | Capabilities |
|---|---|
| **POS / Sales** | Quotation → Sales Order → Reserve → Pick/Pack/Ship → Invoice → Payment → Return/RMA |
| **Purchase / Procurement** | Requisition → RFQ → Comparative Statement → Approval → PO → GRN → 3-Way Match → Supplier Invoice |
| **Inventory** | FIFO · WAC · FEFO · Serial Tracking · Batch Tracking · Expiry Control · Cycle Count · Reorder Alerts |
| **Warehouse** | Zones · Bins · Putaway · Wave Picking · Packing · Dispatch · Barcode Scanning · RFID |
| **Accounting** | Chart of Accounts · Journal Vouchers · Voucher Approval · Bank Reconciliation · Trial Balance · P&L · Balance Sheet · VAT Return |
| **Workflow Engine** | Multi-level Approval · SLA Escalation · Delegation · Mobile Approval Links · Approval History |
| **CRM / Loyalty** | Customer Credit Limits · Loyalty Points · Gift Cards · Customer Advances |
| **HR / Payroll** | Employee Management · Attendance · Payroll Processing |
| **Reports** | Inventory Valuation · Stock Movements · Sales · Purchase · Financial Statements · VAT · Audit Reports |
| **Admin / System** | Module Configuration · Feature Toggles · Audit Logs · Domain Events · Outbox Events · System Health |

### Architecture Highlights

- **Backend:** ASP.NET Core 9 · EF Core · SQL Server · Repository Pattern · Domain Events · Outbox Pattern
- **Frontend:** Angular 17+ · Angular Material · Lazy-loaded Modules · Feature Guards · Permission Guards
- **Security:** JWT Auth · Role-based · Branch Isolation · Warehouse Isolation · Full Audit Trail
- **Accounting Engine:** Double-entry GL · AR/AP · COGS · VAT · Cost Centres · Financial Period Locking
- **Inventory Engine:** FIFO/WAC costing · FEFO picking · Batch/Serial/Expiry · Reserved/In-Transit/Damaged stock layers
